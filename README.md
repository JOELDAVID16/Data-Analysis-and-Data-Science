3. 🍔 Fast-Food Menu Analysis and Product Explorer

Tools: Power BI

Created an interactive dashboard using a McDonald's US menu dataset containing 80 distinct products. The dashboard was designed as a customer-focused product exploration experience rather than a conventional report focused only on averages.

Key Features

* Browse products by category.
* Explore individual product details and descriptions.
* View product prices and preparation times.
* Filter the product table for easier exploration.
* Navigate between category-level and product-level information.

Objective: Design an interactive product enquiry dashboard that helps users explore menu items and compare relevant product information.

Repository: McDonalds-Product-Information

4. 🤖 AI Agent Workforce Integration Analysis

Tools: SQL, SQLiteOnline

Explored the Global AI Agent Workforce Integration 2026 dataset using SQL to investigate AI adoption, productivity, workforce sentiment, deployment costs, governance, and cybersecurity risks.

Key Areas of Analysis

* AI agent adoption across industries.
* Average productivity gains by industry.
* Distribution of primary AI agent roles.
* Employee sentiment toward AI integration.
* Minimum and maximum deployment costs by industry and role.
* Strict AI governance across industries.
* Cybersecurity incidents and industry-level comparisons.

SQL Skills Applied

* Data exploration using SELECT.
* Filtering and grouping using WHERE and GROUP BY.
* Aggregation using COUNT(), SUM(), MIN(), MAX(), and AVG().
* Sorting using ORDER BY.
* Calculations and rounding.
* Subqueries and comparative business analysis.

Objective: Investigate how AI agents are being adopted across industries and compare reported productivity, costs, governance, and cybersecurity indicators.

Repository: Global_AI_Agent_Workforce_Integration_2026
